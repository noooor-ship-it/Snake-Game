# Java Snake Game 🐍

A desktop-based Snake Game developed using Java Swing and AWT. The project demonstrates core Java programming concepts, Object-Oriented Programming, GUI development, and event handling.

## Features

- Responsive keyboard controls
- Smooth snake movement
- Dynamic food generation
- Score tracking
- Collision detection
- Game Over functionality
- Restart option
- Interactive GUI

## Technologies Used

- Java
- Java Swing
- Java AWT
- Object-Oriented Programming

## Key Concepts

- OOP Principles
- Event Handling
- GUI Development
- Game Loop
- Collision Detection
- Keyboard Input Handling

## Project Purpose

This project was developed as an academic project to strengthen Java programming skills and demonstrate practical implementation of GUI-based applications.
